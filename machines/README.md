# Machines-specific Configurations

This directory contains configurations that are specific to every machines no matter
it is a laptop, desktop, or server. The configurations here are not shared across
machines.

## Files

Every folder in this directory is named as exactly the hostname of the machine.
Each machine must contain:

- `config.nix` — the machine's flake configuration entry point.
- `hardware.nix` — originally `hardware-configuration.nix` generated by
  `nixos-generate-config`.

For larger machines the config may be split into capability modules
(e.g. `network.nix`, `services.nix`, `github-runners.nix`) imported from
`config.nix`, so each concern stays in one small file.

But there are also an exception for the `base` folder, which is used for storing configurations
that are shared across machines.
